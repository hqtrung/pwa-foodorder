# Sound Files for Notification

## Current Status
The current sound files are placeholders. You can replace them with real notification sounds from these free sources:

## Recommended Sources
1. **Mixkit** (https://mixkit.co/free-sound-effects/notification/)
   - "Happy bells notification" - for new orders
   - "Digital quick tone" - for status changes  
   - "Urgent simple tone loop" - for urgent alerts

2. **Pixabay** (https://pixabay.com/sound-effects/search/notification/)
   - Free downloads, no attribution required
   - Good selection of notification sounds

3. **Zapsplat** (https://www.zapsplat.com/sound-effect-category/alerts-and-prompts/)
   - Professional quality sounds
   - Free account required

## File Requirements
- Format: MP3
- Duration: 1-3 seconds for notifications
- File size: < 50KB each
- Quality: 44.1kHz, 128kbps minimum

## Installation
1. Download sounds from any of the sources above
2. Rename files to match:
   - `new-order.mp3` - Pleasant chime/bell for new orders
   - `status-change.mp3` - Subtle beep for status updates  
   - `urgent-order.mp3` - More attention-grabbing alert
3. Replace the current empty files in this directory

The sound service will automatically load and use the new files.
